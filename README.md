## Objetivo del trabajo

Diseñar e implementar una base de datos relacional para un sistema de información realista, incluyendo análisis del problema, requisitos, modelo entidad-relación, normalización, implementación en SQL, consultas, vistas, procedimientos almacenados y triggers.

## Estructura del repositorio

- `documentacion/`: análisis, requisitos, MER, DER, normalización y defensa oral.
- `diagramas/`: imágenes del MER y DER.
- `sql/`: scripts SQL del proyecto.
- `entrega/`: archivos finales para entregar.
